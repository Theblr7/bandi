# BANDI Family Tree (Reddy · Pedakanti)

Lightweight, responsive family tree. Single file: `index.html`.

## Publish on GitHub Pages
1. Create a free account at https://github.com and click **New repository**.
2. Name it `bandi-family-tree` and choose **Public**. Click **Create repository**.
3. Click **uploading an existing file**, drag in `index.html`, `.nojekyll` and `README.md` (unzip first), then **Commit changes**.
4. Go to **Settings > Pages**. Under **Branch** choose `main` and folder `/ (root)`, then **Save**.
5. After about a minute your site is live at:
   https://YOUR-USERNAME.github.io/bandi-family-tree/
